# MBP RAG Wiki Generation Pipeline

## Project Overview
Automated agent pipeline that generates wiki documentation for a multi-module Java/Spring Boot project.
Source code is in /home/r.dovgan/cakb/sources/, results go to /home/r.dovgan/cakb/rag/.

## Modules to process (in order, one at a time)
1. mbp-utils
2. redis
3. parent-dal
4. dataaccesslayer
5. core-module
6. channel-integration
7. channel-batch-jobs
8. web-messages
9. mbp

## Rules
- Process modules strictly sequentially. Never start next module until current is fully done.
- For each module, generate exactly 7 wiki files in this order:
  1. overview.md
  2. architecture.md
  3. api-endpoints.md
  4. data-models.md
  5. business-logic.md
  6. configuration.md
  7. integration-points.md
- After generating each file, a reviewer agent checks quality before proceeding.
- If review fails 3 times, mark file as needs-human-review and continue.
- All output goes to /home/r.dovgan/cakb/rag/<module-name>/
- Never modify files in /sources/

## Agents
- Agent-Initializer: reads modules.yaml, creates tasks with dependencies
- Agent-Generator: reads source code, generates wiki markdown files
- Agent-Reviewer: checks each generated file against a quality checklist

## Quality checklist for reviewer
- No hallucinations (class/method names must exist in source code)
- All public methods and endpoints are covered
- Code examples are present
- Minimum length: overview.md >= 500 words, others >= 300 words
- Valid markdown structure
